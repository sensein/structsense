## Overview

This folder contains a demonstration of running **StructSense** in a Python environment.

In this demo, we perform a **Named Entity Recognition (NER)** task using the `test_small.pdf` file.

## Contents
 

- **`.env_example`, `.env_example_partial`**  
   Environment configuration files.

- **`*.json`**  
  JSON-formatted output files generated by StructSense.

- **`run_structsense_partial_extraction_only.py` and `run_structsense_partial_extraction_only_without_key.py`**  
  Script demonstrating StructSense extraction tasks only, two different variants.
 
- **`run_structsense_full_pipeline.py`**  
  Script demonstrating the full StructSense pipeline.
